# MARKET BASE 写真加工ツール UIプロトタイプ V0.2

## 位置づけ
PhotoBaseの写真加工部分だけを独立させた、スマートフォン向けの写真加工専用ツールです。
写真台帳、検索、ログイン、利用者管理、オンラインストレージは含みません。

写真は外部サーバーへ送信せず、通常のCanvas画像処理と手動操作だけで加工します。AIは使用しません。

## 起動方法
このフォルダの中身をGitHub Pagesなどの静的Webサーバーへ、そのまま配置してください。

ローカル確認例：

```bash
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000/` を開きます。

## V0.2で動く主な機能

### 写真の取り込み
- 「写真を選ぶ」「撮影する」の2アイコン
- JPEG・PNG・WEBPなど、ブラウザが読める画像の読み込み
- 背面カメラ起動用 `capture="environment"`

### 写真の調整
- 水平調整：手動スライダー、通常の輪郭計算による水平線推定
- 90度回転
- 切り抜き比率
- 台形補正：4点を指で動かし、透視変換して切り抜き
- 明るさ、コントラスト、彩度、色温度
- 8種類のフィルター
- 画像サイズ設定
- AIを使わない通常補間による2倍・4倍拡大

### 写真への記入
- 日付
- 自由文字
- 円、四角、矢印、線
- 旧品、交換品、故障部品などの回転式ラベル選択
- ①②③の連続番号
- 手書き、半透明マーカー
- 寸法記入
- 寸法端点の磁石吸着
  - 写真内の強い輪郭
  - 画像端、中央ガイド
  - 既存図形、既存寸法の端点
- 部分拡大

### 修正・比較
- モザイク、ぼかし、塗りつぶし
- 手動背景切り抜き
  - 細い、標準、太いブラシ
  - 指でなぞった部分を透明化
  - 元に戻す・やり直す対応
- 2枚比較
  - 左右、上下
  - 旧品／交換品、修理前／修理後などのラベル
  - 合成後も通常の写真として追加加工可能
- 加工前の長押し比較

### 保存
- JPEG、PNG、WEBP
- 画質：高、標準、軽量
- 長辺3840px、1920px、1280px、現在サイズ、2倍
- ファイル名変更
- PNG・WEBPは透明背景を保持
- JPEGは透明部分を白で保存
- OSの共有・保存画面を開く

## V0.2で新たに実装した機能
V0.1で操作画面だけだった次の3機能を、実際の画像処理まで接続しました。

1. 台形補正
2. 手動背景切り抜き・透明化ブラシ
3. 2枚比較合成

また、台形補正と2枚比較は破壊的な加工ですが、元に戻す・やり直すで加工前の画像へ戻せるようにしています。

## AI・オンライン処理
- AIは使用しません。
- 人物・物体の自動認識はしません。
- 生成型の高画質化、不要物の生成消去、OCRは含みません。
- 写真を外部サーバーやオンラインストレージへ送信しません。
- 水平推定と寸法吸着にはSobel法による通常の輪郭計算を使用します。
- 台形補正には4点指定による通常の射影変換を使用します。

## スマホ写真フォルダへの保存
Web/PWA版ではOSの共有・保存画面を開きます。

- iPhone：共有画面から「画像を保存」
- Android：共有またはダウンロードから写真・Pictures等へ保存

ブラウザの制約を受けず、ボタン1回でカメラロールへ直接保存することを保証する場合は、将来ネイティブアプリまたはネイティブラッパー化が必要です。
