# 変更履歴

## v1.7 実機UX改修版（2026-08-02）

### カメラ・動画

- 常設下部ナビと大きな上下帯を外し、カメラプレビューを画面の中心に再構成
- 写真／動画切替をカメラ画像外の上部52px帯へ移し、戻る・設定を線アイコンへ統一
- 撮影サイズを高画質／標準／軽量、撮影比率を4:3／16:9／1:1から選択可能に変更
- 緑を主色から外し、濃紺・スチールブルー・白／グレーへ変更
- 写真／動画切替、基本動画撮影、撮影動画の確認・OS共有を追加
- マイク拒否時は無音動画へ切り替え、無音であることを確認画面へ表示
- 三分割グリッド、中央線、正面撮影ガイド、水平器、3秒／10秒タイマーを追加
- 50Hz→25fps、60Hz→30fpsを対応端末で試行するフリッカー軽減設定を追加
- 写真タップ時のフォーカス制約、長押しAE/AF固定、実露出制約を対応端末で試行
- 実露出非対応時もプレビューと撮影画像へ反映する端末内露出補正を追加
- カメラ許可拒否・起動失敗時に、再試行、標準カメラ、既存写真選択の代替導線を追加
- 撮影ごとの保存確認を廃止し、WORK PHOTO作業フォルダへ自動追加して連続撮影を継続する方式へ変更
- 撮影後は左下サムネイルを即時更新し、写真アプリへの保存はアルバムの一括保存または詳細画面から行う方式へ変更

### GPS・撮影情報

- 保存済み撮影先を現在地との距離で候補表示する処理を追加
- 候補表示・更新時にGPSを最新再取得する方式へ変更
- 明示操作時だけOpenStreetMapへ座標を送り、住所候補を取得する処理を追加
- 写真を外部へ送らない旨と、座標送信の条件を画面上へ明記

### 保存・アルバム・台帳

- 元の解像度、長辺3840px、1920px、1280pxとJPEG画質を端末保存時に選べる導線を追加
- アルバムへ「すべて選択」「選択解除」「選択したN枚を写真アプリへ保存」を追加
- 写真アプリ保存済みバッジと未保存のみフィルターを追加
- iPhoneではOS共有画面から「画像を保存」を選ぶ説明へ統一
- 編集保存の形式、画質、サイズ、任意長辺を前回値として端末内保持
- 保存予定画素数とファイル容量の概算範囲を表示
- 編集画像のWORK PHOTO内アルバム複製を初期OFFにし、必要時だけ選択する方式へ変更
- 写真台帳を常設ナビから外し、アルバムで写真を選択した後だけ表示
- アルバムからカメラへ戻る導線を追加

### エディタ

- モバイル編集画面を1本の上部操作列と下部横スクロールツールへ再構成
- 写真表示領域を拡大し、水平・色・フィルター調整中の背景ぼかしを除去
- 水平調整中に実グリッドを表示
- 明るさ、コントラスト、彩度、色温度に加え、影、ハイライト、シャープを独立調整可能に変更
- 8フィルターへ強度調整を追加
- 全編集初期化を追加し、初期化直前へUndoできる履歴点を作成
- ラベルへ「予備品」「再使用不可」を追加
- 寸法操作を「矢印を先に表示し、位置・長さ調整後にタップしてmm入力」へ変更
- 円、四角、三角、矢印、線を配置後に選択し、中央点で全体移動、端点／頂点／四隅の点で形状調整できるよう変更
- 端点・頂点・四隅を、他図形の端点／角／辺中央／中心、画像端、グリッド、写真輪郭へ吸着するガイドを追加
- 接続した点は吸着先の図形移動へ追従し、吸着ON／OFF、吸着表示、対応端末の短い触覚通知を追加
- 寸法色へ赤／青／緑／黄／白／黒、任意色、前回色保持、全寸法一括色変更、明暗に応じた縁取りを追加
- 主要操作44px以上、表示文字12px以上へ調整

### QA・文書

- 2026-08-02にChromium自動実ブラウザQAを実施し、62／62合格、失敗0を確認
- console error 0、page error 0、request failure 0を確認
- 390×844、375×667、1280×800と、ルート画面・編集画面のオフライン再読込を確認
- 撮影画面の非重複、撮影サイズ／比率、保存確認なし連続撮影、一括保存、保存済み表示、三角形、吸着設定、寸法6色と任意色を追加確認
- iPhone／Android実機受入は未完了として分離
- v1.4とv1.5／v1.6の矛盾を `SPEC_CONFLICT_RESOLUTION_v1.7.md` で解決
- v1.6監査・共通UI文書を旧版参考に変更し、v1.7正本ではないことを明記
