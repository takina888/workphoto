## Pure Webで実機確認が必要な項目

- iPhoneのカメラ・マイク・位置情報権限が初回／再訪時にどう表示されるか
- 実露出、タップAF、AE/AF固定、ズーム、ライト、フリッカー軽減の端末対応
- OS共有画面で複数写真を「画像を保存」した結果と保存済み判定
- 動画形式、音声、向き、写真アプリ保存
- 吸着の指操作感、触覚通知、接続追従の見え方
- 撮影サイズが各端末の取得ストリームで得られる実画素数
