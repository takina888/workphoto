# 正本再基準・Web仕上げ監査

更新日：2026-08-02

## 発生した問題

初期作業でWORK PHOTO以外の引き継ぎ資料を正本と誤認したため、
その後の仮版はWORK PHOTOの正式後継ではなかった。

## v1.5統合再基準での是正

- 仮版を正本系譜から除外した。
- WORK PHOTOの写真編集正本V1.4を正式基盤として復帰した。
- V1.4の高機能編集を `editor/` 以下の権威あるエディタとして保持した。
- カメラ、アルバム、撮影情報、Excel写真台帳、WORK SERIES共通UIを外側シェルに統合した。

## v1.6 Web仕上げでの完了項目

### 外側シェルと遷移

- 重複していた埋め込みエディタを除去し、`editor/` を単一正本とした。
- ルートとエディタの戻り先を同一オリジンの相対パスまたはHTTP(S)に制限した。
- Service Workerを単一ルート管理へ移行した。
- モバイルの下部ナビ、固定操作、タッチ領域を仕上げた。

### 写真台帳

- A4縦・横の各用紙で、9・12・16・20枚を対応した。
- 番号方式を全ページ通し、ページごと、写真ごと手入力から選択可能にした。
- 番号位置を下部見出し、左上、右上から選択可能にした。
- 名前付き書式の保存、読込、複製、削除を実装した。
- 写真ごとの全体表示／枠合わせ、X・Y位置、ズームをプレビューとExcelへ同じ計算で反映した。
- 写真番号、コメント、自由記入欄をExcelの編集可能セルにした。

### 高機能エディタ

- 保存・キャンセルの動作を修正した。
- クロップと回転をプレビューと保存画像へ反映する処理に修正した。
- 出力サイズの指定を実装した。
- 作成済みオーバーレイの再選択・再編集を実装した。
- 連続操作を一つの操作履歴として扱うUndoトランザクションを実装した。

## 監査結論

- v1.6はWeb版として完成している。
- 実ブラウザ最終QAは47 / 47合格、コンソール・ページ・通信エラー0で完了した。
- 受入上の残項目は、iPhone・Android実機確認のみである。
- Web版の範囲外は、写真アプリへの直接保存、EXIF GPS埋め込み、常時フラッシュの3項目に限定する。
