# WORK PHOTO for Machines v1.8 色調整実機修正版

更新日：2026-08-02

## この版の位置づけ

v1.8は、v1.7で明るさ・彩度・フィルター等がiPhone実機上で反映されない問題を修正したWeb/PWA版です。色調整中は長辺720pxの軽量プレビュー、通常表示はタッチ端末で長辺1080px、保存時は指定解像度の分割画素処理を使います。全画素を一括再計算して無反応になる経路と、処理失敗を黙って無視する経路を廃止しました。

公開経路 `recovery-r1/editor` のService Worker参照先、初回以外も毎回キャッシュ解除していた起動処理、カメラ起動直後に露出パネルが再び消える競合も修正しました。Chromium自動実ブラウザQAは完了しました。iPhone Safari／ホーム画面PWAとAndroid Chrome／PWAの最終実機受入は未完了です。

これは過去の企画書・仕様書に含まれる全長期機能の100%実装宣言ではありません。採用仕様と保留仕様の境界は `SPEC_CONFLICT_RESOLUTION_v1.7.md`、機能別状態は `IMPLEMENTATION_MATRIX.md` を正本とします。

## v1.8で維持する採用仕様

- 起動直後はカメラ。常設下部ナビを置かず、写真プレビューを最大化する
- 濃紺・スチールブルー・白／グレーを基本とし、緑は成功状態などに限定する
- 写真／動画を切り替え、動画は基本撮影・確認・端末保存に限定する
- 写真／動画切替は撮影画像外の上部帯へ置き、撮影サイズ3段階と4:3／16:9／1:1を設定できるようにする
- 三分割グリッド、中央線、正面撮影ガイド、水平器、タイマー、50Hz／60Hzフリッカー軽減を撮影設定にまとめる
- 写真タップでピント・露出操作を試行し、非対応端末では露出を端末内画像処理で補う
- カメラ拒否時は再試行、標準カメラ、既存写真選択の代替導線を示す
- 撮影後は確認画面を出さずWORK PHOTO作業フォルダへ自動追加して連続撮影し、写真アプリへはアルバムから複数選択して保存する
- 主保存先はiPhoneの「写真」またはAndroidのギャラリー。WORK PHOTO内アルバムへの編集画像複製は初期OFFとする
- 写真台帳はグローバルナビに置かず、アルバムで写真を選択した後だけ表示する
- 撮影先候補を開くたびGPSを最新再取得し、保存済み近隣候補と住所候補を表示する
- エディタは写真表示領域を優先し、調整パネル表示中も写真をぼかさない
- 寸法は「矢印を先に表示 → 位置と長さを調整 → 矢印をタップ → mm入力」とする
- 図形・寸法は中央点で全体移動、端点／頂点／四隅の点で調整し、点・角・辺中央・中心・画像端・グリッド・写真輪郭へ吸着する
- AI画像解析、生成AI、OCR、写真のクラウドアップロードは行わない

## 主な実装範囲

- フルスクリーンカメラ、前後カメラ切替、対応端末のズーム・ライト、露出・フォーカス試行
- 写真／動画切替、録画時間表示、動画確認、マイク拒否時の無音録画、OS共有
- 撮影補助ガイド、セルフタイマー、撮影モード、フリッカー軽減
- GPS最新再取得、近隣の保存済み撮影先候補、明示操作による住所候補
- 元／3840／1920／1280の写真サイズとJPEG画質を選ぶ端末保存導線
- 高画質／標準／軽量の撮影サイズ、4:3／16:9／1:1、保存確認なしの連続撮影
- 端末内アルバム、ビューア、写真情報、検索、全選択／解除、選択したN枚の一括写真アプリ保存、保存済み表示、未保存フィルター
- 水平、切り抜き、回転、台形、7項目の色調整、8フィルターと強度、画像サイズ
- 円／四角／三角／線／矢印、端点・頂点・四隅の操作点と吸着、文字、日付、ラベル、番号、手書き、寸法mm、角度、部分拡大
- モザイク、ぼかし、塗りつぶし、手動透明化、2枚比較
- Undo／Redo、原画比較、全編集初期化とUndo復帰
- JPEG／PNG／WEBP出力、保存形式・画質・サイズの前回値保持、保存容量概算
- 単一ルートService Workerによる主要画面のオフライン再読込
- 旧Service Worker／旧WORK PHOTOキャッシュを自動解除し、旧キャッシュに存在しない `recovery-r1/` から一式を起動
- 主要操作44px以上、表示文字12px以上の自動確認

## アプリ構成

- `index.html`：写真データを残したまま旧画面キャッシュを解除する起動ページ
- `recovery-r1/index.html`：カメラ、アルバム、ビューア、写真台帳、設定
- `recovery-r1/app.js`：撮影、動画、GPS候補、端末保存、アルバム、台帳の制御
- `recovery-r1/editor/index.html`：写真編集画面
- `recovery-r1/editor/app.js`：iPhone互換の画素処理による端末内編集・書き出し
- `db.js`：写真と設定の端末内IndexedDB保存
- `xlsx.js`：Excel写真台帳生成
- `service-worker.js`：PWAキャッシュの単一ルート管理

## 起動方法

カメラと位置情報はHTTPSまたはlocalhostでのみ利用できます。

```bash
python start_server.py
```

## Pure Web/PWAの制限

- iPhoneの「写真」へ無操作で直接書き込み、保存成功まで検証することはできません。共有画面で「画像を保存」を選びます
- 実センサー露出、タップAF、AE/AF固定、ズーム、ライト、フリッカー軽減はブラウザが公開する機能と端末対応範囲に依存します
- 権限ダイアログの表示頻度はiOS・Android・ブラウザが管理し、アプリ側では強制できません
- カスタムカメラで取得する画像は、標準カメラの最大画素数、HDR、EXIF、GPS保持を保証しません
- 動画形式、音声、写真アプリへの保存可否はMediaRecorderとOS共有機能に依存します
- GPS住所候補は通信可能時だけ利用できます。写真は送信せず、明示操作時に座標だけをOpenStreetMapへ送ります
