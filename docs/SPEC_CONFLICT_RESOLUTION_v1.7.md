## v1.7で確定した製品方針

- WORK PHOTOは現場写真を撮影・編集・端末保存する道具
- AI画像解析、生成AI、OCR、AI超解像を使わない
- 写真をアプリ独自サーバー、クラウドストレージ、画像APIへ送らない
- GPS住所候補だけは、利用者が押した時に座標のみ外部サービスへ送る明示例外
- 元写真を上書きしない
- iPhone写真アプリ／Androidギャラリーを本来の保存先とする
- WORK PHOTO内アルバムは補助的な作業履歴で、編集画像の複製は初期OFF
- 写真台帳は写真選択後に使う文脈機能
- 動画は撮影だけ。編集機能をWORK PHOTOへ詰め込まない
- 写真が見える面積、文字の読みやすさ、片手操作を機能数より優先する

## Pure Web/PWAの限界

次はWeb版で端末横断保証できません。

- 共有画面を経由しないiPhone写真アプリへの直接保存と保存成功の検証
- iPhone全機種での実センサー露出、タップAF、AE/AF固定、フラッシュ、フリッカー軽減
- カメラ・マイク・位置情報権限ダイアログの表示頻度制御
- 標準カメラと同じ最大画素数、HDR、EXIF、GPS
- 音量ボタンを確実にシャッターとして使用すること
- すべての端末で同一動画形式・音声・向きを生成すること

必須化する場合はPhotoKit／AVFoundation等を使うネイティブ版またはネイティブラッパーを別スコープで検討します。
